# Real Time Speech Captioning

> **Development status: Planned.** Repository scaffolding only. No working implementation, experimental results, benchmark figures or completed research findings are claimed.

## Project overview
Real-time speech recognition and accessible captioning experiments.

## Motivation
This project is part of Mohd Rizam Bakar's learning and research portfolio while transitioning from software engineering toward AI science. Its focus is to understand and investigate prototype streaming transcription with authorised or synthetic recordings.

## Research objectives
- Explore transcription accuracy and delay.
- examine accessibility-oriented caption presentation.

## Proposed scope
Prototype streaming transcription with authorised or synthetic recordings.

## Planned technologies
Python, JavaScript, WebSocket, PyTorch. These are proposed tools, not installed dependencies or implemented integrations. Record exact versions when implementation begins.

## Planned experiments or implementations
- Measure recognition error and end-to-end caption delay separately.
- Compare chunk lengths under a fixed test protocol.
- Inspect correction behaviour and caption readability.

## Reproducibility objectives
- Record the research question, assumptions and acceptance criteria before each experiment.
- Pin code revisions and environment/dependency versions; record hardware where relevant.
- Document data sources, licences, preprocessing, splits and random seeds.
- Compare against a stated baseline and report limitations and failure cases.
- Provide runnable commands and reviewed artefact manifests when implementations exist.
- Keep proposals separate from observations; report uncertainty rather than inventing results.

## Current status
**Planned.** Only documentation and repository setup exist. There are no released models, published datasets, benchmark results or participant studies in this repository.

## Research and data responsibilities
This project is exploratory research and is not a clinically validated medical device.
No identifiable participant data will be published. Human-participant experiments
require appropriate research ethics approval before recruitment or data collection.
Datasets and trained models may have licensing requirements separate from the MIT
software license. Computational results must not be presented as demonstrated
benefit to hearing-assistance users without appropriate evidence.
